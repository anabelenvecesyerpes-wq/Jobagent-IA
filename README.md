# 🤖 Agente de empleo-IA

Agente inteligente para ayudar a las personas a encontrar empleo.

## Funciones

- 🔎 Búsqueda de ofertas de empleo
- 📄 Análisis y adaptación de CV
- ✍️ Generación de cartas de presentación
- 🎯 Evaluación de compatibilidad entre candidato y oferta
- 📋 Preparación de candidaturas
- 💼 Gestión y seguimiento de solicitudes

## Tecnología

Backend desarrollado con Python y FastAPI.
Base de datos SQLite.

## Objetivo

Automatizar y simplificar el proceso de búsqueda de empleo mediante inteligencia artificial.
